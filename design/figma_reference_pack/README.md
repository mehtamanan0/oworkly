## Shared visual system

The app uses a **desktop-first enterprise shell** with a compact white horizontal header, OWorkly logo at left, centered product navigation, account/company context at right, and a light grey-blue page background. Primary headings and major buttons use deep navy. Interactive blue, success green, warning orange/amber, destructive red, and expert purple are used consistently. Cards are white with subtle grey borders, 10–16px corner radii, low shadows, and generous internal padding. Tables use compact rows and coloured badges instead of heavy grid lines. Page headers normally include a breadcrumb, title, one-line description, and a right-aligned primary action.

Suggested colour anchors inferred from the prototype: deep navy `#0A1F5A`; primary blue near `#2563FF`; orange near `#F47A20`; success green near `#16A34A`; background near `#F6F8FC`; text near `#111827`; muted text near `#6B7280`; border near `#E5E7EB`. Treat the screenshots as authoritative if exact values differ.
